## 📖 À propos

Application e-commerce pour promouvoir la consommation responsable. Le site respecte les normes **W3C**, **RGAA** et suit les bonnes pratiques **SEO** et **éco-conception**.

**📅 Rendu** : 9 janvier • **Soutenance** : 23 janvier 2026

---

## ✨ Fonctionnalités

-   🏠 **Accueil** - Hero, sélection produits, valeurs de l'entreprise
-   📦 **Catalogue** - Tous les produits disponibles
-   🔍 **Fiche produit** - Détails complets avec retour catalogue
-   📱 **Responsive** - Adapté mobile, tablette, desktop
-   ♿ **Accessible** - RGAA niveau AA
-   ⚡ **Optimisé** - Lighthouse ≥ 80

## 🚀 Installation

```bash
# Cloner le dépôt
git clone https://github.com/VialsShiny/green-market.git
cd greenmarket

# Installer les dépendances
npm install

# Lancer le projet
docker compose up -d --build
```
